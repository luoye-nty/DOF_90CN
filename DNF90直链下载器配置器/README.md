# DNF 直链下载器配置器

配置器与下载器是两个独立 EXE。配置器内部携带下载器模板，生成时复制模板并写入配置；
配置器本身不会变成下载器。

## 构建

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Build-DownloaderSuite.ps1
```

交付产物只有一个：

```text
build\DNF直链下载器配置器.exe
```

## 可配置内容

- 下载器名称，默认 `DNF直链下载器`。
- 多个 HTTP/HTTPS 直链，一行一个，严格按填写顺序下载。
- 默认磁盘，默认 `D`。
- 默认下载文件夹名称，默认 `地下城与勇士安装文件`。
- 生成文件输出目录。

生成的下载器默认保存到：

```text
D:\地下城与勇士安装文件
```

用户也可以修改下载目录。如果选择磁盘根目录，会自动追加配置的文件夹名称。

## 下载完打开安装

生成的下载器提供默认勾选的“下载完打开安装”：

- 下载文件中恰好有一个 EXE：启动该 EXE，并关闭下载器。
- 下载文件中没有 EXE：提示“请手动解压安装”，下载器保持打开。
- 下载文件中有多个 EXE：提示进入下载目录手动选择，下载器保持打开。

压缩包不会自动解压。下载文件名优先使用服务器 `Content-Disposition`，否则根据 URL
或内容类型判断；已有同名文件时会自动添加序号，避免覆盖。
