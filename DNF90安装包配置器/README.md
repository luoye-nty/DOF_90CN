# 落叶DNF 安装包配置器

本项目由两个独立 EXE 组成：

- `落叶DNF安装包配置器.exe`：选择客户端目录并生成安装包。
- `落叶DNF安装程序.exe`：独立安装器模板，负责选择安装路径、解压文件、创建快捷方式。

配置器内部携带安装器模板。生成安装包时，配置器复制安装器模板并追加压缩负载；配置器本身不会变成安装器。

## 构建

在 PowerShell 执行：

```powershell
pwsh -ExecutionPolicy Bypass -File .\Build-InstallerSuite.ps1
```

构建产物：

```text
build\落叶DNF安装包配置器.exe
```

日常分发只需要配置器 EXE。独立安装器模板只作为配置器的构建输入和嵌入资源，
不再输出到 `build` 目录。

构建后可执行完整功能测试：

```powershell
dotnet run --project .\DNF90.Setup.SmokeTest\DNF90.Setup.SmokeTest.csproj -c Release -- .\DNF90.Setup.Builder\RuntimeAssets\落叶DNF安装程序.exe
```

测试会创建模拟客户端，验证分包、分卷生成、SHA256 校验、安装文件哈希和
“不删除目标目录其他文件”。

## 客户端要求

选择的客户端根目录必须包含：

```text
ImagePacks2\
Script.pvf
90CN.dll
```

登录器文件名不固定。选择客户端目录后，配置器会列出根目录下的 EXE，自动优先
选择名称包含“登录器”的文件，也可以手动选择其他文件名。所选登录器的完整文件名
会写入安装清单，安装后的快捷方式和启动动作都按该文件查找。

安装器名称默认为 `Setup.exe`，可以在配置器中修改。
配置器提供“默认安装文件夹”输入项，默认值为 `地下城与勇士`；安装器默认打开
`D:\地下城与勇士`。这个文件夹名称会写入安装清单，并同时用于安装器窗口标题、
顶部名称和根目录安装子文件夹名称。桌面快捷方式名称固定使用登录器文件名。
分卷前缀默认为 `DNF_LY`，只能修改这一段；最终文件名固定为：

```text
前缀_版本号_序号.zip
```

例如：

```text
DNF_LY_1.0.1_001.zip
DNF_LY_1.0.1_002.zip
```

配置器会生成以下独立压缩分区：

- `DNF_LY_版本号_001.zip`：Script.pvf
- `DNF_LY_版本号_002.zip`：落叶DNF登录器、90CN.dll 和其他全部剩余文件
- `DNF_LY_版本号_003.zip` 起：ImagePacks2 分卷（默认每个目标 4 GB）

所有分卷统一使用 ZIP Fastest 级别的 Deflate 真实压缩，并根据 CPU 核心数并行
处理多个分卷。该模式比 LZMA2 快很多，压缩率通常低于高压缩模式；如果 NPK 本身
已经接近不可压缩数据，最终体积仍可能接近原始客户端大小。

## 发布形式

生成的文件直接放在同一个目录：

```text
Setup.exe
DNF_LY_1.0.1_001.zip   （PVF）
DNF_LY_1.0.1_002.zip   （登录器配件）
DNF_LY_1.0.1_003.zip
DNF_LY_1.0.1_004.zip
DNF_LY_1.0.1_005.zip
...
```

安装清单直接写入 `Setup.exe`，安装器直接从自身所在目录读取同名版本对应的 `.zip`
分卷，不再创建 `Setup.packages` 目录，也不需要单独的 `manifest.json`。
分发时只需保持安装器 EXE 和 ZIP 文件在同一目录。

安装器会校验每个分区的 SHA256，按客户端目录结构覆盖同名文件，但不会主动删除目标目录中的其他文件。
安装完成后左侧“关闭”按钮会恢复可用，“开始安装”会变为不可用的“安装完成”。
安装中和安装完成后都不能再修改路径、选择文件夹或重复点击安装；安装完成后
左侧关闭按钮和窗口右上角关闭按钮均可正常关闭安装器。
如果用户在安装器里选择磁盘根目录（例如 `D:\`），实际安装目标会自动使用配置器
填写的文件夹名称，例如 `D:\地下城与勇士`；选择普通目录时不会额外增加子目录。

## 发布内容

配置器的第 4 项可以选择：

- 全量发布：生成 PVF、登录器配件和全部 ImagePacks2 分卷。
- PVF 发布：只重新生成 `001.zip`。
- NPK 发布：只重新生成 ImagePacks2 的 `003.zip` 及后续分卷。
- 登录器配件发布：只重新生成 `002.zip`，内容包含登录器、90CN.dll 和其他剩余文件。

单项发布固定使用分卷模式，不依赖之前是否做过全量发布。重复发布会覆盖相同编号和名称的 `.zip`，不会删除其他分卷。
